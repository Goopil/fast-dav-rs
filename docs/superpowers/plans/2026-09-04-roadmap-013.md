# Roadmap 0.13 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the 0.13 protocol surface — RFC 6638 scheduling, RFC 8607 managed attachments, RFC 7809 calendar-timezone, typed `current-user-privilege-set` — as 4 independently mergeable packages (S1–S4), then release 0.13.0.

**Architecture:** All new HTTP goes through the existing `WebDavClient::send`/`propfind`/`report` pipeline. New XML props are added to `DavItem` + the `ElementName` mapping in `webdav/streaming.rs` (precedent: `calendar_home_set`, `calendar_timezone`). CalDAV-only features live in `caldav/` as thin methods on `CalDavClient`; the DAV:-namespace privilege feature lives in `webdav/`. Parsing of iCalendar bodies stays caller-side (`icalendar`).

**Tech Stack:** Rust (edition 2024, MSRV 1.85), hyper 1.x, quick-xml (streaming parse), no new dependencies.

## Global Constraints

- Provider A is never named in repo artifacts; no production URLs (smoke tier reads `PROVIDER_A_DAV_URL`).
- Always run cargo with `CARGO_TARGET_DIR=target`.
- Gates before every push: `cargo fmt --all --check`; `cargo clippy --all-targets --all-features -- -D warnings`; `cargo nextest run --all-features --locked --test unit_tests`; `cargo test --doc --all-features`; `cargo test --all-features --locked --no-run` (compiles ALL test binaries — e2e compile errors must be caught locally, 0.12 lesson).
- PR CI: **14/14 checks verified explicitly** (`gh pr checks <n>`) before merge. Squash merge. CHANGELOG conflicts resolved by union.
- SonarCloud: coverage ≥80% new code, duplication ≤3% (share via `webdav/`, never copy caldav↔carddav).
- No uids/tokens interpolated into log lines or assert messages (CodeQL flags them).
- All public APIs: doc comments + `no_run` doc examples that compile (`cargo test --doc`). New types `#[non_exhaustive]`. New `Error` variants never (use `UnexpectedStatus`).
- Re-export pattern: `caldav/mod.rs` → `webdav/mod.rs` → `lib.rs` flat list (skip the crate root on name clashes — AUDIT-014 convention).
- No TODO/FIXME comments. English docs.
- Wire tests use `tests/unit/common/http_helpers.rs` (`serve_sequence`, `serve_capture`, `response_head`); e2e tests need fixtures up (`./radicale-test/setup.sh`, SabreDAV at `http://localhost:8080/`).
