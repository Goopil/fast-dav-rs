# Adversarial Roast — September 2026 (pre-0.11.0)

Full-crate adversarial review performed before the 0.11.0 release: four independent
read-only review passes (WebDAV core, CalDAV/CardDAV/Sync, v1.1 features, HTTP
semantics), every HIGH/MEDIUM finding then re-verified line-by-line against the
source and the RFC texts. Baseline: main @ `ac8f1d3`.

Scope exclusions: known findings AUDIT-001..032 (`FINDINGS.md`) and documented
deferrals are not re-listed here.

**Total: 37 unique findings — 2 HIGH, 20 MEDIUM, 14 LOW, 1 SECURITY.**

Remediation is grouped into 7 parallel work packages, tracked by issues
#136–#142. Merge order recommendation: #137 → #138 → #136 → #139 → #140 → #142 → #141.
